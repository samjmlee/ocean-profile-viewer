Methods and data coverage
  • Native imported observations, sorted by pressure within each phase. No conductivity calibration is fitted by this viewer. See the workspace provenance for the actual processing level and conversion.
  • Time series use a separate median for each selected phase within ±0.125 dbar of the target. Out-of-range targets stay missing. The shared cursor uses profile time, not an instantaneous pause measurement.
  • Profile x axes and the observed dbar range can be fitted automatically or fixed manually. Points show individual samples. Connected lines are a visualization, not additional observations.
  • 2D supports multiple phase overlays. The workspace's Phase for 3D selector chooses one separate phase for a 3D curtain.
